\subsection{Dataset}

Telemetry of each cell was recorded using Measurement and Control Units (MCU1--MCU8) and exported using the ASAM Measurement Data Format (MF4). \subsection{Test Protocols}
Each cell underwent four discharge protocols across various ambient temperatures: Constant, Pulse, Hybrid Pulse Power Characterization (HPPC), and the Worldwide Harmonised Light Vehicles Test Cycle (WLTC) (Fig. \ref{fig:protocols}). Testing was divided into three sequential phases (Table \ref{tab:phase_soh_summary}):

\begin{enumerate}
	\item \textbf{Initial measurements:} Baseline testing on fresh cells across all four protocols.
	\item \textbf{Accelerated aging:} Cyclic aging using constant 1C discharge cycles at $25^{\circ}\text{C}$.
	\item \textbf{Post-aging measurement:} Re-testing using the baseline protocols.
\end{enumerate}

\subsection{Pre-processing Pipeline}
As per the dataset engineer's advice, voltage (V), current (A), temperature (T), and ambient temperature ($T_{amb}$) are primary channels recorded from the test platform's sensors.
The components of the pre-processing pipeline are as follows:

\begin{enumerate}
	\item \textbf{Extract discharge instances:} Using discharge start/end signals provided by the testing platform to filter only discharge instances.
	\item \textbf{Hierarchical Data Format (HDF5):} Converting each discharge instance away from MF4 to HDF5 allows for O(1) disk reads when loading the dataset, while also only taking primary channels (V, I, T, $T_{amb}$) to reduce memory usage.
	\item \textbf{Static conditions metadata:} $T_{amb}$ is controlled by the test platform at a fixed value for each discharge instance, thus an average value was taken and stored as an HDF5 attribute.
	\item \textbf{Statistics metadata:} Statistics (mean, $M_2$, bounds) are stored as HDF5 attributes for standardization.
	\item \textbf{SoH metadata:} SoH is calculated for each discharge instance and written to HDF5 attributes (detailed below in Section D).
\end{enumerate}

\subsection{SoH Labeling}
Raw SoH for each discharge instance was computed via Coulomb counting:

\begin{equation}
	\text{SoH}_{\text{raw}} = \frac{\int_{t_{\text{start}}}^{t_{\text{end}}} |I(t)| \, dt}{C_{\text{nom}}}
\end{equation}

Because measured capacity varies with discharge rate and $T_{\text{amb}}$, reference points were filtered from $1\text{C}$ discharge cycles at $25^\circ\text{C}$. A 4th degree polynomial was then fitted over the cycle indices to establish SoH trajectories for each MCU (Fig. \ref{fig:soh_trajectories}). Reference-only SoH ranges and cycle counts are found in Table \ref{tab:mcu_soh_summary}.

\subsection{Statistics}
Global dataset statistics are computed across all $N = \sum N_i$ time steps using the pre-aggregated file metadata ($N_i$, $\mu_i$, $M_{2,i}$) for normalization:

\begin{equation}
	\mu = \frac{\sum_i N_i \mu_i}{N}, \quad \sigma = \sqrt{\frac{\sum_i M_{2,i} + \sum_i N_i \mu_i^2 - N \mu^2}{N}}
\end{equation}

For scalar attributes, sample-wise mean and variance are calculated across all $K$ discharge instances (Table \ref{tab:feature_stats}).

\section{Methodology}

\subsection{Problem Formulation}
Given a sequence of $V$, $I$, and $T$ over a discharge instance, conditioned on $T_{\text{amb}}$, an estimator function $f(\cdot)$ predicts the cell's $\text{SoH}$:

\begin{equation}
	\widehat{\text{SoH}} = f(V, I, T \mid T_{\text{amb}})
\end{equation}

\subsection{Estimator Architecture}
Input sequences pass through three 1D Convolutional Neural Network (1D-CNN) blocks (32, 64, 128 channels; GroupNorm, GELU, dropout), followed by Feature-wise Linear Modulation (FiLM) conditioning on $T_{\text{amb}}$:

\begin{equation}
	\text{FiLM}(h) = \gamma(T_{\text{amb}}) \odot h + \beta(T_{\text{amb}})
\end{equation}

where $\gamma$ and $\beta$ are learned affine parameters. The modulated features pass through a 2-layer bidirectional Gated Recurrent Unit (BiGRU), whose final hidden states are concatenated and projected to a scalar SoH estimate.

\subsection{Training Setup}
The dataset was sliced into 1500-timestep windows (\textasciitilde15 min) with stride 500. The eight MCUs were split 6/1/1 into training, validation, and test sets. MCUs 3 and 8 were held out for validation and testing, respectively, as their SoH bounds fall within the training range, testing interpolation rather than extrapolation. All input sequences and conditions were normalized. Estimator hyperparameters are given in Table \ref{tab:estimator_hparams}.

\subsection{Results and Discussion}
Evaluation was performed on the validation and testing MCUs across phases (Table \ref{tab:baseline_results}) and across temperature bands and discharge protocols (Table \ref{tab:temp_protocol_results}).

\input{baseline_results.tex}

$R^2$ is negative for Initial ($-0.71$), an artifact of its narrow SoH range ($91.8$--$96.2\%$): with little target variance, $R^2$ amplifies residual error and becomes uninformative, so RMSE and \%Err are the meaningful metrics here. Most overall metrics derive from the aging phase, which achieves low error, likely due to limited variance in discharge protocol (1C discharge at 25\textdegree C).

Initial reaches $1.2\%$ error (RMSE $0.016$). Aging is the strongest phase ($R^2 = 0.89$, $1.2\%$ error, RMSE $0.013$): its constant 1C discharge yields a consistent waveform the CNN/BiGRU exploits, while still tracking declining SoH across discharges.

Notably, Initial and Aging achieve similar metrics despite Initial having far fewer cycles and greater protocol/temperature variance, suggesting the model generalizes well across both phases despite varying temperatures. Post-Aging error rises to $3.8\%$ (RMSE $0.034$), likely because MCU SoH trajectories diverge after accelerated aging (Fig.~\ref{fig:soh_trajectories}), producing a less-represented distribution in training. Overall, $R^2 = 0.020$ and $1.8\%$ error across $62.8$--$96.2\%$ SoH.

\input{temp_protocol_results.tex}

The $40^{\circ}\text{C}$ band achieves the highest fit among temperature slices ($R^2 = 0.96$, $1.9\%$ error), while $-20^{\circ}\text{C}$ trails slightly ($R^2 = 0.94$, $2.7\%$ error) and $-10^{\circ}\text{C}$ shows the lowest fit among the higher-cycle bands ($R^2 = 0.86$, $4.3\%$ error). Notably, $-20^{\circ}\text{C}$ is $45^{\circ}\text{C}$ from the $25^{\circ}\text{C}$ baseline, versus $15^{\circ}\text{C}$ for $40^{\circ}\text{C}$, so its $R^2 = 0.94$ reflects generalization across a larger temperature shift than the $40^{\circ}\text{C}$ result.

Within each temperature band, the estimator performs consistently across the SoH spectrum. $-20^{\circ}\text{C}$ spans $68.1$--$93.7\%$ at $R^2 = 0.94$ and $40^{\circ}\text{C}$ spans $66.8$--$95.1\%$ at $R^2 = 0.96$, so degradation capture holds across the full SoH range within a given temperature, not only at its extremes.

Across discharge protocols, the model generalizes well, with each protocol spanning multiple temperature bands (Table~\ref{tab:phase_soh_summary}). Constant and HPPC achieve the highest fits ($R^2 = 0.92$ and $0.99$), and Pulse follows ($R^2 = 0.95$). WLTC has an $R^2$ of -0.11, but this reflects $3$ cycles restricted to the Initial phase, giving a narrow SoH band ($92.1$--$95.3\%$) (Table~\ref{tab:phase_soh_summary}).

\subsection{Permutation Feature Importance (PFI)}

PFI was used to measure which inputs the model relies on for its predictions. PFI shuffles one feature at a time and measures the resulting drop in performance.
\begin{equation}
	\Delta \text{RMSE}_{j} = \text{RMSE}_{\text{perm}(j)} - \text{RMSE}_{\text{base}}, \quad j \in \{I, V, T, T_{amb}\}
\end{equation}

Shuffling across the entire dataset ignores that each discharge protocol constrains the plausible range of every signal. To preserve physically valid combinations, stratification shuffles each feature only within its own protocol. Results are reported per protocol in Table~\ref{tab:pfi_results} and plotted in Fig. \ref{fig:pfi_importance}.

\input{pfi_results.tex}

\begin{figure}[H]
	\centerline{\includegraphics[width=\columnwidth]{pfi_importance.pdf}}
	\caption{PFI results over $I$, $V$, $T_{amb}$, $T$.}
	\label{fig:pfi_importance}
\end{figure}

$I$ and $T_{amb}$ are consistently the most important features across protocols. $V$ is also an important feature across all protocols. $T_{amb}$ and $T$ show an interesting relationship with protocol dynamics: under Constant discharge, both features are utilized ($+0.0130$), while under HPPC and Pulse, $T_{amb}$ rises ($+0.1383$, $+0.1563$) as $T$ drops to near zero or negative. This is likely due to stable currents allowing $T$ to accumulate larger deltas, which is a more useful signal compared to the fixed ambient condition, whereas under highly dynamic current profiles, the cells can dissipate accumulated heat, so the model only has $T_{amb}$ as a proxy for temperature.
