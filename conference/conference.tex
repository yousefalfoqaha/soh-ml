\section{Data Processing}
\subsection{Dataset}
The dataset used was obtained from the Scienlab SL1007A charge-discharge testing platform, where eight Samsung INR21700-50E lithium-ion cells were tested from fresh SoH levels to beyond EOL. Telemetry of each cell was recorded using Measurement and Control Units (MCU1--MCU8) and exported using the ASAM Measurement Data Format (MF4). \subsection{Test Protocols}
Each cell underwent four discharge protocols across various ambient temperatures: Constant, Pulse, Hybrid Pulse Power Characterization (HPPC), and the Worldwide Harmonised Light Vehicles Test Cycle (WLTC) (Fig. \ref{fig:protocols}). Testing was divided into three sequential phases (Table \ref{tab:phase_soh_summary}):

\begin{enumerate}
	\item \textbf{Initial measurements:} Baseline testing on fresh cells across all four protocols.
	\item \textbf{Accelerated aging:} Cyclic aging using constant 1C discharge cycles at $25^{\circ}\text{C}$.
	\item \textbf{Post-aging measurement:} Re-testing using the baseline protocols.
\end{enumerate}

\subsection{Pre-processing Pipeline}
As per the dataset engineer's advice, voltage (V), current (A), temperature (T), and ambient temperature ($T_{amb}$) are primary channels recorded from the test platform's sensors.
The components of the pre-processing pipeline are as follows:

\begin{enumerate}
	\item \textbf{Extract discharge periods:} Using discharge start/end signals provided by the testing platform to filter only discharge periods.
	\item \textbf{Hierarchical Data Format (HDF5):} Converting each discharge period away from MF4 to HDF5 allows for O(1) disk reads when loading the dataset, while also only taking primary channels (V, I, T, $T_{amb}$) to reduce memory usage.
	\item \textbf{Static conditions metadata:} $T_{amb}$ is controlled by the test platform at a fixed value for each discharge period, thus an average value was taken and stored as an HDF5 attribute.
	\item \textbf{Statistics metadata:} Statistics (mean, $M_2$, bounds) are stored as HDF5 attributes for standardization.
	\item \textbf{SoH metadata:} SoH is calculated for each discharge period and written to HDF5 attributes (detailed below in Section D).
\end{enumerate}

\subsection{SoH Labeling}
Raw SoH for each discharge period was computed via Coulomb counting:

\begin{equation}
	\text{SoH}_{\text{raw}} = \frac{\int_{t_{\text{start}}}^{t_{\text{end}}} |I(t)| \, dt}{C_{\text{nom}}}
\end{equation}

Because measured capacity varies with discharge rate and $T_{\text{amb}}$, reference points were filtered from $1\text{C}$ discharge cycles at $25^\circ\text{C}$. A Piecewise Cubic Hermite Interpolating Polynomial (PCHIP) was then fitted over the cycle indices to establish SoH trajectories for each MCU (Fig. \ref{fig:soh_trajectories}).

\begin{figure}[htbp]
	\centerline{\includegraphics[width=\columnwidth]{soh_trajectories.pdf}}
	\caption{Fitted SoH trajectories for all eight MCUs across their full discharge cycle histories.}
	\label{fig:soh_trajectories}
\end{figure}

\subsection{Statistics}
Global dataset statistics are computed across all $N = \sum N_i$ time steps using the pre-aggregated file metadata ($N_i$, $\mu_i$, $M_{2,i}$) for normalization.

\begin{equation}
	\mu = \frac{\sum_i N_i \mu_i}{N}, \quad \sigma = \sqrt{\frac{\sum_i M_{2,i} + \sum_i N_i \mu_i^2 - N \mu^2}{N}}
\end{equation}

For scalar attributes, sample-wise mean and variance are calculated across all $K$ discharge instances (Table \ref{tab:feature_stats}).

\section{Methodology}

\subsection{Problem Formulation}
Given a sequence of $V$, $I$, and $T$ over a discharge period, conditioned on $T_{\text{amb}}$, an estimator function $f(\cdot)$ predicts the cell's $\text{SoH}$:

\begin{equation}
	\widehat{\text{SoH}} = f(V, I, T \mid T_{\text{amb}})
\end{equation}

\subsection{Estimator Architecture}
The estimator's architecture uses 1D Convolution Neural Network (1D-CNN) blocks (conv, norm, GELU, dropout), followed by a bidirectional Gated Recurrent Network (BiGRU), then a final pooling layer to predict an SoH value. The estimator is conditioned using Feature-wise Linear Modulation (FiLM):

\begin{equation}
	\text{FiLM}(h) = \gamma(T_{\text{amb}}) \odot h + \beta(T_{\text{amb}})
\end{equation}

where $h$ is the intermediate feature map, $\gamma(\cdot)$ and $\beta(\cdot)$ are learned affine parameters generated from $T_{\text{amb}}$, and $\odot$ denotes element-wise multiplication.

\subsection{Training Setup}
For baseline testing, the dataset was sliced into 2000 timestep windows (approx. 30 minutes) with a stride of 500. The MCUS were organized into a 5, 1, 1 split for the training, validation and testing sets respectively. Additionally, normalization was applied to all input sequences and conditions.
